# OmniRoute Backend

**Backend services** for OmniRoute — the AI-powered retail operations platform.

This repository hosts the APIs and services that power inventory, sales, suppliers, intake, analytics, and AI-assisted store workflows used by the OmniRoute frontend.

![TypeScript](https://img.shields.io/badge/TypeScript-5-blue?logo=typescript)
![Node.js](https://img.shields.io/badge/Node.js-20+-339933?logo=node.js)

---

## Overview

OmniRoute Backend is designed to support real-time and near-real-time retail operations:

- Inventory ledgers and stock levels
- Sales and transaction telemetry
- Supplier and purchase-order workflows
- Intake / receiving
- Analytics and operational metrics
- Hooks for AI features (floor audit, suggestions)

> **Status:** Repository scaffolding. Application code is under active development.

---

## Planned / target stack

- Node.js + TypeScript
- Modular API architecture (NestJS or Express-style services)
- REST (and optionally real-time) endpoints for the OmniRoute dashboard
